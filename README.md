## Features

mpvRx focuses on a streamlined, high-performance Android media player experience built around mpv. It combines clean visual design with practical playback customization.

- Core player
  - libmpv-based Android video player
  - High-performance playback
  - Efficient, low-noise media experience
  - Advanced playback controls
  - Serious video player with a cleaner UI

- Theme and UI system
  - 25+ color themes
  - AMOLED pure black variants
  - Dynamic / Material You theming
  - Material 3 expressive UI
  - Themed player controls
  - Always-dark mode option
  - Animated player controls
  - Custom app icon styles

- Gesture controls
  - Double-tap seek zones
  - Multi-tap continuous seeking
  - Horizontal swipe-to-seek
  - Long-press speed boost
  - Pinch-to-zoom and pan
  - Volume boost via gesture
  - Swap volume/brightness sides

- Video quality and rendering
  - HDR10 / HLG / BT.2020 / linear HDR modes
  - OpenGL/Vulkan backend switching
  - Automatic black-bar cropping
  - Smart render backend selection

- Subtitle system
  - Primary and secondary subtitle support
  - ASS override modes
  - Custom subtitle styling
  - Online subtitle search
  - Subtitle font management
  - Explicit subtitle off option

- Player controls and layout
  - Customizable control layout zones
  - 25+ player button types
  - Custom user buttons
  - Landscape/portrait layouts
  - One-tap unlock
  - Double-back unlock
  - More sheet access
  - In-player settings
  - Hide button backgrounds
  - Centralized controls

- Orientation and viewport
  - 8 orientation modes
  - Per-video orientation persistence
  - Smart video-aware orientation

- File browser and navigation
  - Dual browser modes: album and tree view
  - Folder pinning
  - Single-child auto-flatten
  - Auto-scroll to last played
  - Recursive media counts
  - New badges
  - Grid/list layouts
  - SMB / FTP / WebDAV support
  - Syncplay room support
  - Responsive and dual-pane layouts
  - Audio library mode
  - Home-first navigation flow
  - Swipeable main tabs

- Music and audio library
  - Local music browsing
  - Multiple music source selection
  - Library filters
  - Dedicated now-playing view
  - Lyrics support
  - Audio playlist and favorites
  - Audiobook library support
  - Audiobook playback and bookmarks

- Scripting and editing
  - Lua and JavaScript support
  - Built-in code editor
  - Runtime script loading
  - Lua module support
  - Built-in mpv.conf and input.conf editor

- Utilities
  - Stats page with system data
  - Video compressor
  - Video filter presets
  - Custom skip segments
  - A-B loop
  - Frame navigation
  - Sleep timer
  - Adaptive background playback
  - Unified background playback
  - Notification styles
  - Safe area / window offset
  - Display cutout support
  - Brightness memory
  - Automatic local playlist discovery
  - Playlist cover support
  - Dynamic refresh rate
  - Secure folder protection
  - Screenshot templates

- Build and distribution
  - Standard APK variant
  - Universal APK build
  - Signed release workflow support
  - In-app update support
